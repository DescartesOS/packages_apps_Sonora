# Sonora

Music for **DescartesOS**, with Material 3 Expressive styling, a glass player, and a redesigned setup and lyrics menu.

Developed by [lostsignal-502](https://github.com/lostsignal-502).

Built on [ArchiveTune](https://github.com/rukamori/ArchiveTune) by Rukamori and contributors, with glass and lyrics adaptations from [BitChord](https://github.com/kushagrasinghx/BitChord) and [SimpMusic](https://github.com/maxrave-dev/SimpMusic).

Licensed under [GPL-3.0](LICENSE). Copyright © Rukamori and ArchiveTune contributors for their original contributions.

ROM module: `Sonora` at `packages/apps/Sonora`. Builds import `prebuilt/Sonora.apk`; regenerate it with `scripts/update-rom-prebuilt.sh`.
